# Veille quotidienne sur Claude AI

Avant de préparer le cours (ou le récap hebdo), toujours faire une recherche web fraîche. Ne
jamais s'appuyer uniquement sur la connaissance interne du modèle (elle peut être obsolète) :
utiliser l'outil de recherche web pour vérifier l'état réel des fonctionnalités à la date du jour.

## Requêtes suggérées (adapter le mois/l'année courants)

- "Anthropic Claude changelog release notes [mois année]"
- "Claude AI new features [mois année]"
- "Claude Code new features [mois année]"
- "Anthropic Claude Skills Projects Artifacts update"
- "site:anthropic.com Claude release notes"
- "site:docs.claude.com what's new"

## Sources à privilégier

- Pages officielles Anthropic (docs.claude.com, anthropic.com/news, changelog produit)
- Annonces officielles de nouvelles fonctionnalités (connecteurs, Skills, Artifacts, Projects,
  API/Agent SDK) — filtrer le bruit marketing, ne retenir que ce qui change concrètement l'usage.

## Pour chaque nouveauté jugée importante, préparer

1. Ce qui a changé (avant/après)
2. Ce que cela permet de faire de nouveau
3. Pourquoi c'est intéressant (gain concret)
4. Dans quels cas l'utiliser
5. Comment l'utiliser (étapes)
6. Un exemple concret
7. Un exercice pour la tester immédiatement

Si la nouveauté est jugée suffisamment importante, elle devient le sujet prioritaire du jour (voir
`priority-engine.md`, niveau 1) même si un autre sujet était pressenti.

## Si l'outil de recherche web n'est pas disponible dans la session

Certaines sessions déclenchées automatiquement peuvent démarrer avec un jeu d'outils réduit. Si
aucun outil de recherche web n'est utilisable, NE PAS bloquer le cours pour autant : baser le
sujet du jour sur la progression réelle (fondamentaux, approfondissement, cas d'usage pro — voir
`priority-engine.md` niveaux 2 à 6) et l'indiquer explicitement dans le cours (« veille web non
disponible dans cette session, sujet choisi sur la base de la progression »). Ne jamais prétendre
avoir fait une recherche qui n'a pas eu lieu.

## Traçabilité

Toute nouveauté abordée doit être ajoutée à la page Notion « 🆕 Nouveautés Claude » avec sa date
de détection, et référencée dans le cours du jour correspondant.
